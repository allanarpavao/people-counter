# People Counter

A simple browser-based people counter app.

## Purpose

This project demonstrates a minimal web application that tracks how many people have entered a space. It includes a basic HTML interface, styling, and JavaScript logic to increment a displayed count when a button is clicked.

## Files

- `index.html` — page structure and button markup
- `styles.css` — visual styling for the page and button
- `index.js` — button handler and count update logic

## Usage

1. Open [People Counter](https://allanarpavao.github.io/people-counter/)
2. Click the `INCREMENT` button to increase the count.
3. The current count appears in the `People entered:` display.

## Notes

- The app runs entirely in the browser.
- No build steps or server setup are required for basic usage.
